One office joke, one line, under 200 characters. The program writes it
deterministically to `/output/entry.txt`, where a judge model compares it
pairwise against the other entries.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> I asked IT for a second monitor and got a second meeting about why I need a second monitor.

91 characters, single line, no trailing newline.
